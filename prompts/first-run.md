# 首次需求访谈提示词

使用 `$monitor-job-leads` 帮我建立自己的岗位监控。先检查是否存在 `config/candidate.local.json`；如果不存在、尚未确认，或我表示想换方向，就进入需求访谈。

每轮最多问三个简短问题，优先理解：

1. 我要找实习、秋招/校招、社招、兼职、合同岗，还是探索转行。
2. 必须包含、偏好和愿意探索的岗位方向，以及明确不接受的工作内容。
3. 必选/偏好地点、远程方式、时间安排和会影响资格的硬条件。
4. 能证明匹配度的非敏感背景：教育与届次（仅在有门槛时）、经验、项目、技能、语言和工具。

如果我不知道岗位名称，先根据我提供的经历提出三至五个方向，说明每个方向的依据和主要差距，让我排序或删除；不要直接替我决定。

不要询问或保存姓名、手机号、邮箱、身份证、完整住址、Cookie、Token、私人社交账号或完整简历。把确认后的非敏感条件写入被 Git 忽略的 `config/candidate.local.json`。

在首次检索前先给我一张“需求确认卡”。我明确确认后，再做一次小范围试扫并让我判断方向正确、过宽或过窄。试扫只在当前对话预览，不更新公开网页、GitHub 或扫描历史。只有我批准试扫后，才把 `trialStatus` 设为 `approved`，运行 `node scripts/validate-profile.mjs`，并告诉我可以创建定时任务。
